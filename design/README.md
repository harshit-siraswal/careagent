# CareAgent Interface Concepts

This directory contains the first visual interface exploration for CareAgent.

Design stance: soft clinical companion.

Key requirements represented:

- Mascot named Caro.
- Soft and appealing theme.
- Mascot animation for breathing, blinking, pulse, and urgent state.
- Patient app screens for home, device connection, chat/documents, and urgent escalation.
- Caretaker dashboard screen.
- Health readings show source and freshness.
- Critical risk state is visually distinct.

Files:

- `interface-concepts.html` - rejected first visual direction.
- `interface-concepts-v2.html` - minimal friendly app direction.
- `interface-concepts-apple.html` - Apple-style interface direction based on the provided reference.
- `apple-careagent-flow.html` - v5 Apple-style PRD/TRD-driven app flow with 24 screens and the Caro mascot.
- `user-flow-v5.md` - product journey map explaining setup, daily care, devices, documents, channels, risk, emergency, and caretaker flows.
- `assets/caro-mascot.svg` - reusable Caro mascot asset inspired by the supplied healthcare robot reference.
- `remotion-caro-animation-spec.md` - Remotion animation guidance for the mascot.
- `screenshots/` - generated PNG interface images.

Open the HTML file directly in a browser, or use Playwright screenshots from the same file.
